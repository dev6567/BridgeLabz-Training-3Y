Responsive CSS Cheat Sheet

Filters

filter: grayscale(100%); changes how an element looks.

Media Queries

@media (max-width: 700px) { ... } applies rules at set widths.

Responsive Design

Layouts that adapt to any screen size.

Typography

font-size: clamp(1rem, 2vw, 1.5rem); scales text fluidly.

Flexbox

display: flex; arranges items in a row or column.

Grid

display: grid; builds two-dimensional layouts.
